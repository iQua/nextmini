## How Throughput Was Measured

The throughput numbers come directly from `examples/multicast-docker/scripts/multicast_node.py`.

- `format_throughput()` converts `bytes / elapsed_seconds` into `MiB/s` and `Mbps`.
- Sender measurement:
  - starts at `send_start_time = time.perf_counter()`
  - calls `dataplane.send_data(...)`
  - waits for completion with `dataplane.lossless_wait(...)`
  - ends at `send_end_time = time.perf_counter()`
  - throughput bytes = total payload file size
- Receiver measurement:
  - starts at `recv_start_time = time.perf_counter()`
  - calls `dataplane.receive_data(...)`
  - waits for completion with `dataplane.lossless_wait(...)`
  - ends at `recv_end_time = time.perf_counter()`
  - throughput bytes = `expected_bytes` from metadata when present

Important detail:

- sender throughput includes source-side payload read/build plus the send/wait interval
- receiver throughput measures receive-session completion time up to `lossless_wait(...)`
- the later `get_data_buffer()` read and artifact file write happen after the receiver timer stops

Relevant code locations:

- `format_throughput()`: `examples/multicast-docker/scripts/multicast_node.py:260`
- sender timing: `examples/multicast-docker/scripts/multicast_node.py:473-498`
- receiver timing: `examples/multicast-docker/scripts/multicast_node.py:533-567`
