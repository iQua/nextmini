## How Throughput Was Measured

The throughput numbers come directly from `examples/multicast-docker/scripts/multicast_node.py` and are now aligned with the `ns-lossless` metric style.

Sender measurement:

- call `dataplane.send_data(...)`
- start `send_start_time` after the send session is created
- wait for completion with `dataplane.lossless_wait(...)`
- stop the timer at completion
- divide total payload bytes by that elapsed time

Receiver measurement:

- call `dataplane.receive_data(...)`
- wait for completion with `dataplane.lossless_wait(...)`
- read `ReceiverProgress.first_completed_block_at()`
- measure steady-state elapsed time from first completed block to completion
- divide total payload bytes by that steady-state elapsed time

For receiver context, the script also logs the full-session wall time from receive-session start to final completion.

Relevant code locations:

- sender timing: `examples/multicast-docker/scripts/multicast_node.py`
- receiver timing: `examples/multicast-docker/scripts/multicast_node.py`
- Python receiver progress bridge: `python-api/src/lib.rs`
- `ns-lossless` receiver metric source: `dataplane/src/node/integration_test/mod.rs`
