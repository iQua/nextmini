# Arbutus setup notes (legacy)

The `examples/arbutus` directory contains legacy setup notes and assets from early large-scale deployments on Compute Canada’s Arbutus cloud.

Those materials may reference older project names and older deployment assumptions. They are kept as historical context rather than a maintained guide.

If you are deploying Nextmini on a new set of VMs today, start from:

- [Bare Metal Deployment](bare-metal.md) (native binaries + SSH deployment scripts)
- [Public network deployment (no swarm)](public-network.md) (Docker compose across VMs)
- [Configuration Reference](../design/config-reference.md)
