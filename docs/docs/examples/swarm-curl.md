# swarm-curl (legacy)

`examples/swarm-curl` contains notes and manifests for running an external client/server “curl through Nextmini” scenario on a multi-machine Docker Swarm deployment.

This setup is environment-specific (placement constraints, public IPs, swarm node labels), so treat it as a starting point rather than a maintained walkthrough.

If you are validating SOCKS5/MAX proxy flows, prefer the single-machine examples first:

- [SOCKS5 proxy examples (curl / wget / splice-test)](proxy.md)
