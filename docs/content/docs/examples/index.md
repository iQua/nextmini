title: "Examples"
description: "Guided scenarios for local, networked, distributed, workload, and deployment testing."
---

Use these examples to run and validate Nextmini in different environments.

- `Local`: single-machine and small topology workflows.
- `Networking`: namespace and multicast-focused setups.
- `Workloads`: higher-level app and training workloads.
- `Distributed`: multi-node or multi-datacenter deployments.
- `Deployment`: infrastructure-specific rollout guides.
